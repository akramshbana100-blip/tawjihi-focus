# Tawjihi Pomodoro

Flip-clock Pomodoro study timer (HTML/CSS/vanilla JS PWA) with 7 image themes.

## Deploy on GitHub Pages
1. Create a repository and upload the contents of this folder (keep the structure, including `.nojekyll`).
2. Settings → Pages → Deploy from a branch → `main` / root → Save.
3. Open `https://<user>.github.io/<repo>/`. All paths are relative, so project sub-paths work.

Run locally with `python3 -m http.server` (service worker and YouTube need http, not file://).

## Structure
`index.html` · `css/themes.css` · `js/themes.js` · `sw.js` · `manifest.json` · `icons/` · `assets/bg/` (7 WebP backgrounds + thumbnails)
